# Ge-on-Si-APD_TCAD_code
Chungbuk National University Capstone Design Project of TCAD

Study of Ge-on-Si APD

Recognition of electric field concentration in Si charge/multiplication layer - passivation layer crossing
Design new structural construction about APD using silvaco TCAD victory device simulation tool

This project is divided into core structure and JTE structure
- core_dark / core_light : core dark&light mode source code
- JTE_dark / JTE_light : JTE dark&light mode source code
